# 《三国志·战略版》战报收集器 - 核心提示词与对话上下文资产库

## 提示词 1：项目全景角色与工程规范（System / Master Prompt）

```text
你是一名顶级逆向工程与 Windows 桌面自动化专家。我们正在为官方 PC 桌面端端游《三国志·战略版》（进程名 S3Client.exe，窗口类名 EJOY2DX）开发一款自动化战报收集与归档系统。

【核心约束】
1. 绝对零封号：严禁使用 ReadProcessMemory 内存钩子，严禁使用 MITM 本地代理抓包，必须基于展示层视觉自动化（OCR + 图像指纹 + 鼠标模拟）。
2. 零技术门槛交付：用户为 30~55 岁普通游戏玩家，界面必须是单按钮傻瓜式操作，自动管理员提权（解决 Windows UIPI 拦截）。
3. 严禁安卓模拟器：只运行在官方 PC 桌面客户端上。

【技术栈】
Python 3.12 + pywin32 + winocr (Windows 原生高精度 OCR) + mss (DX 极速抓屏) + OpenCV (cv2) + PIL (ImageDraw) + Tkinter GUI。

【代码行为规范】
- 每次鼠标点击必须具有闭环状态校验（等待目标页面出现或消失）。
- 绝不使用死板写死坐标，全部采用动态 OCR 文本框或 DPI 相对百分比标定。
- 绝不在战报中间坐标超链接区域盲点，必须避障点击左侧友军安全横幅。
```

## 提示词 2：两步法第一步——视觉瞄准校准（Zero-Click Calibration）

> 💡 **用途**：在不破坏任何游戏界面的前提下，先在真实屏幕画面上画靶心，自检坐标精度，确认 100% 对齐后再写点击。

```text
我们要分步开发《三国志·战略版 电脑模拟器》的战报截图脚本。之前失败是因为一次性写太复杂且坐标盲猜。现在请严格按照我的【两步法】执行，绝不准跳步：

【第一步：视觉瞄准校准（绝不点击鼠标！）】
1. 请写一个校准脚本 calibrate.py，使用 win32gui 找到类名为 "EJOY2DX" 或标题包含 "三国志·战略版" 的窗口，先调用 ctypes.windll.shcore.SetProcessDpiAwareness(2) 屏蔽 Windows 缩放干扰，并获取其客户区真实宽高 (W, H)。
2. 截取当前窗口画面（目前画面停留在战报交战列表页）。
3. 请不要点击鼠标！在截图上用醒目的红色十字和圆圈，标出以下 8 个关键点击位置的相对百分比坐标，并保存为 debug_aim.png：
   - 点位1~6：列表中间从上往下 6 根折叠细条（【第六场】到【第一场】）的中心点（X 约为 0.35~0.50，Y 均匀分布）。
   - 点位7：当某根细条展开成大卡片时，点击进入详情页的位置（胜/平/败大字或友军战旗位置）。
   - 点位8：右上角【返回】按钮的位置（X 约为 0.94，Y 约为 0.04~0.08）。
4. 运行 calibrate.py 生成 debug_aim.png，然后请你（AI自己）务必调用图像查看工具亲自查看 debug_aim.png！检查点位1~6是否精准落在了6根折叠条的中心，点位8是否落在了右上角返回按钮上。如果偏了，请你根据看到的图片自行微调百分比并重新生成，直到8个红圈100%对准目标！对准后向我汇报，等待我确认后再写点击逻辑。
```

## 提示词 3：连战组（鏖战多穿）原生双击/展开状态机提示词

> 💡 **用途**：解决端游连战条目单点不弹详情页、导致备用逻辑死循环的核心提示词。

```text
在《三国志·战略版》官方 PC 客户端中，战报列表存在两类完全不同的卡片形态：
1. 普通单场战报：点击卡片 ➔ 立即弹进全屏【战斗回放】详情页。
2. 连战组（鏖战多穿，如 5 场连战）：点击某一行条目，游戏仅在当前列表下方展开该场的军队对战信息，并不会直接弹进详情！必须接着点击展开后的军队卡片（或双击），才能真正进入【战斗回放】详情页。

请编写一个确定性的连战消费流水线：
- 识别当前屏所有连战子场次列表（Round 1 到 Round N）；
- 循环：点击第 i 场 ➔ 确认下方展开 ➔ 点击展开卡片 ➔ 等待进入战斗回放 ➔ 高清原图截图 ➔ OCR 提取真实对战双方与时间戳 ➔ dHash 查重去重 ➔ 点击右上角返回按钮 ➔ 闭环校验退回列表；
- 循环结束后，当前屏幕所有场次标记已处理，执行平滑线性下拉翻页。
```
