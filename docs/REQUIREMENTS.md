# 《三国志·战略版》PC官方桌面端战报自动收集系统 - 需求规格说明书

## 1. 项目背景与业务价值
《三国志·战略版》（以下简称“三战”）作为大型多人在线重度沙盘 SLG，高活跃玩家与同盟管理团队每日会产生海量的 PVP 战报（单日通常在数十至上百场）。
目前绝大多数玩家仍使用手机手动截图、微信传输到电脑、再手动重命名归档，工作极其繁琐、费时费力且极易漏采漏报。
本项目旨在打造一款专为**官方 PC 桌面客户端**（`S3Client.exe`）定制的、轻量级、绝对安全、开箱即用的自动化战报采集工具。

---

## 2. 用户画像与硬性约束

### 2.1 用户画像
* **年龄圈层**：30~55 岁成熟玩家、同盟管理、团长或重度配将爱好者；
* **技术背景**：绝大多数非技术人员，无法接受复杂的命令行、环境变量配置、驱动安装或模拟器调试；
* **核心诉求**：**极致傻瓜、一键运行、高度稳定、双手彻底脱离**。

### 2.2 核心硬性约束
1. **绝对零封号底线（Account Safety First）**：
   * **严禁内存读写（ReadProcessMemory / Hook）**：严禁侵入游戏进程内存，避免被阿里 ACE 反作弊判定为外挂封停 30 天；
   * **严禁网络封包劫持（MITM / 代理劫持）**：严禁篡改本地证书或监听游戏专有 TCP 加密协议流；
   * **唯一合法路径**：严格限制在 Windows 展示层与人眼视觉层（纯视觉截图 + OCR + 鼠标行为模拟）。
2. **严禁依赖安卓模拟器（No Emulators）**：
   * 用户明确拒绝使用雷电、MuMu、逍遥等模拟器（占用资源大、卡顿）；
   * 必须原生支持灵犀互娱官方 PC 桌面客户端（`S3Client.exe`，窗口类名 `EJOY2DX`）。
3. **零门槛交付（Single Click Launch）**：
   * 桌面生成单快捷方式，双击即用；
   * 必须具备 Administrator 权限自提权机制（解决 Windows UIPI 权限隔离导致的鼠标事件吞噬）。

## 3. 核心功能需求清单

### 3.1 游戏窗口锁定与 DPI 规范化
* **窗口捕获**：自动识别并锁定 `S3Client.exe` 进程，支持通过类名 `EJOY2DX` 与标题关键字多重寻径；
* **DPI 穿透**：强制启用 `SetProcessDpiAwareness(2)`，抹平 Windows 100%、125%、150% 缩放以及 2K/4K 高分屏带来的坐标畸变；
* **分辨率自适应**：
  * 支持标准化归一（1280×720 标准尺寸）；
  * 同时通过动态 OCR 相对坐标体系，自适应 1080p 全屏、最大化或自由缩放窗口。

### 3.2 战报列表智能遍历
* **标签页自动对齐**：检测并自动从大地图进入【战报】主界面，并自动切换至【交战】PVP 标签页；
* **连战组（鏖战多穿）专项处理**：
  * 识别一组多场连续交战的折叠条目（如 `鏖战 5 场`、`斩获战功 6975`）；
  * 按照场次序号（第 1 场 ➔ 第 2 场 ➔ ... ➔ 第 N 场）由浅入深按序展开与采集，杜绝死循环原地踏步；
* **单场战报顺序消费**：
  * 识别画面中的单场战报卡片；
  * 严格按屏幕 Y 轴自上而下顺序消费，消费完打上已录标记。

### 3.3 高清战报详情截取与结构化提取
* **详情页触发**：点击战报卡片安全热区，闭环等待【战斗回放】全屏界面渲染完成；
* **全屏原图保存**：捕获 1:1 原始高清无损图像，不压缩画质以保留战损数字清晰度；
* **OCR 结构化识别**：
  * 战报发生日期与时间（格式：`YYYY-MM-DD HH:MM:SS`）；
  * 战斗胜负结果（胜 / 败 / 平）；
  * 双方玩家名字、阵营与主要战损。

### 3.4 智能去重与按日自动归档
* **双重唯一性校验**：
  1. **时间戳 Slug 校验**：`YYYY-MM-DD_HHMMSS`；
  2. **图像差异哈希（dHash）校验**：提取战报核心画面的 64 位感知哈希指纹，汉明距离 `<= 4` 判定为完全同一份战报，秒级过滤重复项；
* **层级化存储**：
  * 根目录：`战报导出/`；
  * 子目录：按战报发生日期自动分门别类，例如 `战报导出/2026-10-24/`；
  * 文件命名规范：`{日期}_{时间}_{胜负}_战报_{序号}.png`。

### 3.5 三大安全防护盾（闭环容错）
1. **闭环返回防护**：通过 OCR 实时锁定右上角【返回】按钮正中心，点击后轮询校验详情页是否真正消失，未退出则重试，绝不把详情页当成列表页；
2. **大地图脱困护盾**：若因玩家手动误触或坐标跳转进入世界大地图（识别到底部武将、政厅），1 秒内自动点击左下角【战报】并切回【交战】归位；
3. **退出确认弹窗自动关闭**：若误触 ESC 或关闭按钮弹出“确认退出游戏”对话框，自动点击【取消】消除模态阻塞。

---

## 4. 非功能性指标
* **单张采集耗时**：单场战报从点击 ➔ 渲染 ➔ 截图 ➔ OCR ➔ 保存 ➔ 返回，平均耗时控制在 `1.8 ~ 2.5 秒`；
* **CPU / 内存占用**：后台静默运行时 CPU 占用 `< 5%`，内存占用 `< 150MB`；
* **稳定性指标**：支持单次连续无故障采集 100~200 份战报，触底（无新战报）或达到历史日期后自动优雅停止。
